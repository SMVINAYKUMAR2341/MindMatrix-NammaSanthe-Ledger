Place Tesseract trained data files here (auto-downloaded at build time):

  kan.traineddata   (Kannada)
  eng.traineddata   (English)
  hin.traineddata   (optional, Hindi — ML Kit Devanagari covers this too)

Download from:
  https://github.com/tesseract-ocr/tessdata_best
  https://github.com/tesseract-ocr/tessdata

These files are bundled in the APK and copied to internal storage on first OCR run.
